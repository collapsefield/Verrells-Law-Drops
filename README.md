# Current Verrell’s Law Position

Verrell’s Law is currently presented as a **falsifiable retained-state selection framework**.

The current non-trivial claim is not simply that memory can matter.

It is that, under controlled conditions, a preregistered retained-state compatibility measure should predict a stable directional change in later candidate-relative selection within a declared test regime.

Current category-level definition:

> **Retained-State Selection is the controlled study or process by which information preserved from prior states is permitted to influence selection among presently available candidate outcomes.**

The current framework does **not** require:

- a universal electromagnetic memory field;
- external storage of personal memory;
- consciousness as the selection mechanism;
- modification of general relativity;
- quantum collapse as the explanation of ordinary computational behaviour;
- CAAI software behaviour as proof of new physics.

# Current Collapse Aware AI Position

Collapse Aware AI is the separate proprietary engineering track developed by Inappropriate Media Limited.

CAAI is middleware for **governed retained-state behavioural selection**.

The current engineering principle is:

> **Retained history is eligible evidence, not automatic authority.**

A host supplies the current situation and the genuinely permitted candidate actions/behaviours. Retained state may influence which permitted candidate wins, while final selection remains bounded and inspectable.
